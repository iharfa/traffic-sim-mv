# Traffic Sim MV

Live traffic microsimulation for the Greater Malé Region — currently **Hulhumalé Phase 1 + 2**, with Malé to follow.

No build step, no backend: a static page (MapLibre GL + a canvas overlay) running an IDM car-following model entirely in the browser.

## Features

- **84 km directed road graph** built from OSM (oneway, maxspeed, lanes preserved), with carriageway widths from OSM `width`/`lanes` tags and a class-based fallback (primary 13 m, tertiary 9 m, residential 7 m, service 4.5 m)
- **8 vehicle types** — motorcycles, cars, taxis, pickups, lorries, buses, buggies, bicycles — each toggleable with its own count slider and IDM parameters (length, acceleration, headway, top speed)
- **Pedestrians** walking a separate 49 km footpath/sidewalk graph
- Global density multiplier, pause, 1–8× sim speed
- **Traffic signals**: click a junction to place a 2-phase signal (bearing-clustered approaches, 20 s green / 3 s amber); vehicles queue on red; persisted in localStorage
- Left-hand traffic, per-lane queues on multi-lane roads
- Basemaps: Esri World Imagery, **HDC drone orthomosaic (Nov 2025)**, OSM — plus a width-scaled road overlay

## Data

`data/network.json` is generated by `prep.mjs` from an Overpass dump of Hulhumalé
(`node prep.mjs path/to/osm_roads.json`). Vehicle and pedestrian graphs are split at
junctions; 95 marked pedestrian crossings are carried through for future use.

## Run

Any static server, e.g.:

```bash
npx http-server -p 8123
```
