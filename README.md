# Traffic Sim MV

Live traffic microsimulation for the Greater Malé Region — currently **Hulhumalé Phase 1 + 2**, with Malé to follow.

No build step, no backend: a static page (MapLibre GL + a canvas overlay) running an IDM car-following model entirely in the browser.

## Features

- **68 km directed road graph from HDC's official GIS** (CMP road centerlines), snapped and noded so junctions connect cleanly
- **Carriageway widths measured from the Land Use Plan**: for each road, the perpendicular gap between the lot parcels flanking it (minus sidewalks) — no HDC layer stores width directly
- **8 vehicle types** — motorcycles, cars, taxis, pickups, lorries, buses, buggies, bicycles — each toggleable with its own count slider and IDM parameters (length, acceleration, headway, top speed)
- **Road editor**: no HDC layer records one-way direction or lane counts, so click any road in Edit mode to set direction (arrows mark one-way streets) and lanes; edits persist in the browser and export as `overrides.json` (commit it to `data/` to make edits the default for everyone)
- **Pedestrians** walking the street network at sidewalk offset
- **Traffic signals**: click a junction to place a 2-phase signal (20 s green / 3 s amber); vehicles queue on red; persisted locally
- Global density multiplier, pause, 1–8× sim speed; left-hand traffic, per-lane queues
- Basemaps: Esri World Imagery, **HDC drone orthomosaic (Nov 2025)**, OSM — plus a width-scaled road overlay

## Data

`data/network.json` is generated by `prep.mjs` from two HDC ArcGIS exports:

- `CMP_ROAD_CENTERLINES` (FeatureServer) — road geometry, names, phase
- `Lot_Layer` / LUP parcels — polygons used to measure road widths

```bash
node prep.mjs path/to/roads_hdc.json path/to/lots.json
```

The prep snaps dangling endpoints (≤8 m) onto neighbouring lines, splits lines at
every crossing, probes carriageway width at 5 points per edge, and estimates lanes
from width (≥14 m → 4, ≥6 m → 2, else 1) — all overridable in the app.

## Run

Any static server, e.g.:

```bash
npx http-server -p 8123
```
